Janta Auto Parts — Inventory Management
A MERN inventory management dashboard for managing shop products, prices, and stock.
Live Demo https://shop-inventory-zt2o.onrender.com/

Security note: This version does not include authentication. Do not use it for sensitive or real business inventory data until access protection has been added.

Features
- Add, view, search, edit, and delete products
- Search by product name or supplier
- Newest-first product sorting
- Calculate selling price from MRP and discount, or enter a selling price manually
- Increase and decrease stock
- Confirmation before deleting a product
- Responsive dashboard UI
- Toast notifications
Tech Stack
- React + Vite
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- Axios
- Render (deployment)
